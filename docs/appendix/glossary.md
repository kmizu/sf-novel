# 用語集

## Ω（オメガ）
創造主、神の名称。ギリシャ文字の最後の文字で「終わり」と「完成」を象徴。

## アイン＝ウル（Ein-Ur）
Ωライブラリの管理者。ヘブライ語で「無」（アイン）と「始まり」（ウル）を意味。

## Ωライブラリ
地下第14層に存在し、全ての可能性を記録する巨大な図書館。

## 観測者
Ωライブラリへのアクセスを許可された特別な人物。世界中に12人存在。

## 多世界解釈
量子力学における解釈の一つ。あらゆる量子事象において全ての可能性が実現し、平行世界が分岐するという理論。

## 自由意志論
人間の選択における自由意志の存在と性質に関する哲学的議論。

## 神義論（テオディシー）
神が全知全能で完全に善であるなら、なぜ世界に悪や苦痛が存在するのかという神学的問題。
